# Design history

These documents record how the studio was designed. They are kept for context and are not maintained.

- [`PROJECT_SPEC.md`](PROJECT_SPEC.md): the original specification the first five build phases followed. Code comments cite its section numbers (for example "§5.3").
- [`IMPROVEMENT_SUGGESTIONS.md`](IMPROVEMENT_SUGGESTIONS.md): a review written after those phases. Every item on its roadmap (§8) has since been implemented.

Where either document disagrees with the code, the code and [`../protocol.md`](../protocol.md) are right.
